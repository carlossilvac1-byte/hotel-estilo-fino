# Publicar no GitHub Pages — Hotel Estilo Fino

1. No GitHub, crie o repositório **público** `hotel-estilo-fino`.
2. **Add file → Upload files**: envie TODO o conteúdo da pasta, mantendo as subpastas
   (`assets/`, `banco/`, `fonts/`, `icons/`, `vendor/`) e o arquivo `.nojekyll`.
   **Não envie** `banco/02-administrador.sql`.
3. **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main` / `(root)` → **Save**.
4. Em **Actions**, aguarde "pages build and deployment" ficar verde (1 a 3 min).
5. Endereço: `https://carlossilvac1-byte.github.io/hotel-estilo-fino/`

## Instalar no celular
- **Android (Chrome):** abra o endereço → menu ⋮ → *Instalar app*.
- **iPhone (Safari):** abra o endereço → Compartilhar → *Adicionar à Tela de Início*.
- **Computador (Chrome/Edge):** ícone de instalar na barra de endereço.

## Nova versão
Atualize juntos `config.js` (versao), `service-worker.js` (VERSAO) e `versao.txt`.
Arquivo novo entra também na lista `ARQUIVOS` do service worker.
